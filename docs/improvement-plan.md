# Improvement plan

Everything known to be open after build steps 1–18 ([framework-blueprint.md](framework-blueprint.md)): rough edges in
what was built, findings on dev that still need an answer, and the next pieces of work. Each item is triaged:

- **High**: a correctness gap, or something that can turn CI red for no real reason. Do first.
- **Medium**: makes a check stricter, a test steadier, or the suite more complete.
- **Low**: polish, cost, or waits on someone else.

Effort is rough: **S** under an hour, **M** a few hours, **L** a day or more. Items marked *owner* need a decision
from the repository owner before work starts (AGENTS.md: Folio bugs, weaker guards, changes to a step's plan,
anything outside this machine).

## Suggested order

1. **H1**: the independent review first, since it may add items here.
2. **H2** and **H3**: the first run and the visual routine, the two things most likely to hurt someone new.
3. **M1–M6**: tighten the checks and steady the tests.
4. **M7**, which needs the owner, then **M9–M13** and the new journeys.
5. **Low** items as time allows. L13 and L14 happen when Folio or Playwright moves.
